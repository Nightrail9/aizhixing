## 选择合适的数据结构

列表适合有顺序的集合，字典适合按键查找。类型选择会直接影响代码是否容易阅读。

```python
lessons = ["变量", "函数", "文件"]
progress = {lesson: False for lesson in lessons}
```

## 用函数建立边界

函数应当完成一个明确动作，并通过参数显式接收依赖。尽量让返回值可预测，测试自然会更容易。
