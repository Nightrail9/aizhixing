## 为什么要从环境开始

可重复的环境让“在我电脑上可以运行”变成任何人都能验证的结果。我们使用独立虚拟环境隔离项目依赖。

## 创建第一个项目

```bash
python -m venv .venv
```

激活环境后建立 `main.py`：

```python
def greet(name: str) -> str:
    return f"你好，{name}！"

print(greet("AI知行"))
```
