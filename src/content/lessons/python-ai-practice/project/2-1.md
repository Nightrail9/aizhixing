## 定义输入和输出

先写清工具接收什么、返回什么，以及失败时如何说明。一个可验证的边界比复杂界面更重要。

## 分离模型调用

```python
def summarize(client, text: str) -> str:
    if len(text.strip()) < 20:
        raise ValueError("文本太短，无法形成可靠摘要")
    return client.summarize(text)
```

## 处理异常

为网络超时、配额限制和空响应提供不同反馈。不要把内部堆栈直接展示给最终用户。

## 完成标准

准备三个正常输入和三个异常输入，确认程序的行为与提示都符合预期。
