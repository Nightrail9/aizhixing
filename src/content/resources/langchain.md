## 项目简介

LangChain 提供模型接口、提示词、文档检索、工具调用和 Agent 等模块，适合快速组合大模型应用。

## 核心能力

- 标准化模型与消息接口。
- 检索器、向量库与文档处理组件。
- 可组合的 Runnable 数据流。
- 工具调用与 Agent 编排。

## 安装方式

```bash
pip install langchain
```

## 快速开始

从一个最小模型调用开始，再按真实问题逐步引入检索或工具。避免为了使用框架而增加不必要的抽象层。

## 应用场景

适合知识问答、结构化信息抽取、研究辅助和需要连接外部工具的工作流。
